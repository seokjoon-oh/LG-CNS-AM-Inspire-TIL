## Step 1. 웹 서비스 이해

### 1-6강. 요약 및 정리

#### 1. HTML의 기본 구조

HTML은 태그(Tag)를 이용하여 웹페이지의 구조와 내용을 작성한다.

**HTML 태그 작성 형식**

```html
<tag attribute="value">text</tag>
```

- `tag`: HTML 요소를 나타내는 태그
- `attribute`: 태그에 적용할 속성
- `value`: 속성에 지정하는 값
- `text`: 태그 내부에 작성하는 내용

**HTML 파일 저장 및 실행**

- `Ctrl + S`를 눌러 작성한 코드를 저장한다.
- VS Code에서 `Open with Live Server`를 실행하면 브라우저에서 HTML 파일을 확인할 수 있다.

#### 2. CSS의 기본 구조

CSS는 HTML 요소에 스타일을 적용하는 데 사용한다.

**CSS 작성 형식**

```css
selector {
    property: value;
}
```

- `selector`: 스타일을 적용할 HTML 요소를 선택
- `property`: 적용할 스타일 속성
- `value`: 속성에 지정할 값

**CSS 선택자**

- `body` 선택자를 사용하면 HTML의 `<body>` 요소에 스타일을 적용할 수 있다.
- HTML의 `class` 속성을 이용해 특정 요소에 스타일을 적용할 수 있다.

**CSS 파일 연결**

- HTML 문서에 스타일시트(Stylesheet)를 연결하여 CSS 파일을 적용할 수 있다.
- 이를 통해 브라우저에 표시되는 웹페이지의 디자인을 변경할 수 있다.

**HTML 주석**

```html
<!-- CSS -->
```

HTML에서는 `<!-- -->` 형식을 이용해 주석을 작성한다.

#### 3. JavaScript와 이벤트 처리

JavaScript는 웹페이지에서 사용자 동작에 따른 기능을 구현하는 데 활용된다.

**JavaScript 연결**

- HTML 파일에 JavaScript를 연결하여 동적인 기능을 구현할 수 있다.
- 이벤트 핸들러(Event Handler)를 이용해 특정 이벤트가 발생했을 때 동작을 처리한다.

**이벤트와 백엔드 통신**

- 사용자가 프론트엔드에서 버튼을 클릭하면 이벤트가 발생한다.
- 이벤트 핸들러를 통해 필요한 작업을 수행하고, 백엔드에 데이터를 전달할 수 있다.
- 이를 통해 프론트엔드와 백엔드가 연동되는 과정을 이해할 수 있다.

**HTML 요소 접근**

- CSS에서는 `class` 선택자를 이용해 HTML 요소에 스타일을 적용할 수 있다.
- JavaScript에서는 `id` 등을 이용해 특정 HTML 요소에 접근할 수 있다.

#### 4. 브라우저 개발자 도구

브라우저에서 `F12`를 누르면 개발자 도구(Developer Tools)를 실행할 수 있다.

이를 통해 웹페이지를 구성하는 HTML, CSS, JavaScript와 관련된 정보를 확인할 수 있다.
